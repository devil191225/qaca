# Disclaimer & Legal Notice

## Purpose
QACA (Quantum-Adaptive Crypto-Agility) is a **research simulator** for studying
post-quantum cryptographic migration strategies. It generates synthetic data
and causal graphs — it does not implement production cryptographic primitives
and should not be used as cryptographic software in any production system.

## Authorized Use
- ✅ Academic research on post-quantum cryptographic agility
- ✅ Modeling and simulation of crypto-migration strategies
- ✅ Educational use

- ❌ Using as production cryptographic software
- ❌ Any application where cryptographic correctness is required
